How it works

Each agent writes its output into shared session state, and the next agent reads it. That is the SequentialAgent pattern.

  1. 🔥ExaAgentLatest AI news from Twitter / X
  2. 🐳TavilyAgentBenchmarks & provider analysis
  3. 🍥SummaryAgentMerges & structures findings
  4. 🕷️FirecrawlAgentScrapes Nebius model catalogue
  5. 🔍AnalysisAgentNemotron Ultra 253B deep analysis

Run it live

Bring your own keys. This page has no backend: your keys go straight from your browser to each provider and are never sent anywhere else. They are kept only if you tick “Remember”.

Advanced: models & endpoint

ℹ️ Exa’s API doesn’t allow direct browser requests (CORS). If that call is blocked, this web version fetches X/Twitter posts through Tavily (restricted to x.com / twitter.com). The Python ADK version calls Exa directly.
